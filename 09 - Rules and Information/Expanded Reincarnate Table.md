Because of the amount of books we have, I've expanded the Reincarnate table to incorporate a D1000. To roll a D1000, you just need to do the following:
1. Roll 3D10s. One is hundreds, one its tens, one is ones.
2. Each '0' (10 on some dice) you roll is a 0, except if every roll is a 0 which makes it 1000.
3. Example: if you roll 0,6,7 in that order it means 067.
